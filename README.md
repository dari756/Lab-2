# Лабораторная работа №2

## Обнаружение аномалий и выбросов в данных

**Датасет:** `Housing.csv`

### Содержание

В репозитории находится выполненная лабораторная работа по обнаружению аномалий и выбросов:

1. Загрузка и профилирование данных.
2. Проверка нормальности распределения.
3. Обнаружение выбросов методами Z-score и IQR.
4. Многомерное обнаружение аномалий методом ближайших соседей.
5. Сравнение Евклидовой и Манхэттенской метрик.
6. Анализ для `k = 5, 7, 9, 10`.
7. Анализ устойчивости результатов при изменении `k`.

### Файлы

- `Lab_2_Housing.ipynb` — основной Jupyter Notebook с кодом, графиками, результатами и выводами.
- `Housing.csv` — исходный датасет.

### Запуск

1. Установить Python 3.
2. Установить необходимые библиотеки:

```bash
pip install pandas numpy matplotlib scipy scikit-learn jupyter
```

3. Открыть Jupyter Notebook:

```bash
jupyter notebook
```

4. Открыть `Lab_2_Housing.ipynb`.
5. Убедиться, что `Housing.csv` находится в той же папке.
6. Выполнить ячейки ноутбука последовательно.
